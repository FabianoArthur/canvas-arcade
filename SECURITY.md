# Security policy

Canvas Arcade is a static, client-only web app: no backend, no accounts, no cookies, no
analytics. The only thing it stores is high scores and the sound preference, in your
browser's `localStorage`.

## Reporting a vulnerability

Please **do not open a public issue**. Use GitHub's
[private vulnerability reporting](../../security/advisories/new) for this repository
instead. You can expect a first reply within a week.

Only the latest version on `main` (the one deployed to GitHub Pages) is supported.
